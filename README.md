## Flagship project

### Active Directory Identity Lifecycle Automation

> **Problem:** Manual identity administration can create duplicate accounts, incorrect access, incomplete offboarding, and weak audit evidence.

I created PowerShell workflows for CSV-based onboarding and ticketed offboarding in Active Directory. The solution validates requests and AD dependencies, prevents duplicate accounts, uses secure password entry, supports `-WhatIf`, removes access during separation, and produces a structured audit trail.

**Workflow:** Request validation → account provisioning or offboarding → group and access changes → verification → audit log

**IAM relevance:** `Provisioning` `Deprovisioning` `Identity Operations` `Access Revocation` `Automation` `Audit Evidence`
